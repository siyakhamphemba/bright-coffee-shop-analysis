# Looker Studio Dashboard - Bright Coffee Shop

## Overview
This dashboard presents the sales performance analysis for Bright Coffee Shop (January - June 2023). It provides interactive visualizations for executive decision-making.

## Dashboard Link
[Click here to view the live dashboard](https://datastudio.google.com/reporting/314d13c1-f362-4e92-8dc2-94004eead138)

## Pages

### Page 1: Executive Overview
- **KPIs:** Total Revenue ($623,586), Transactions (149,116), Avg Transaction Value ($4.18)
- **Charts:** Revenue by Category, Revenue by 30-Minute Time Bucket
- **Slicers:** Month, Product Category

### Page 2: Product & Time Analysis
- **KPIs:** Total Units Sold (214,470), Avg Units per Transaction (1.44)
- **Charts:** Revenue by Day, Revenue by Type, Top 10 Products, Bottom 10 Products
- **Slicers:** Store Location, Product Type
